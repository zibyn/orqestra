# project

2026-10-28, whole-project re-init of shadcn on Base UI with style base-vega (replacing legacy new-york on radix). Verdict: done, build passes.

## Changed

- `components.json`: style new-york → base-vega, baseColor zinc → neutral, plus new CLI fields (rtl, menuColor, menuAccent, registries).
- `src/styles.css`: removed all the TanStack template styling (sea/lagoon tokens, Fraunces/Manrope fonts, body gradients, .island-shell, .nav-link, .feature-card, .site-footer, rise-in keyframes...). It now holds only the stock base-vega theme, plus the typography plugin that was already installed.
- `src/lib/utils.ts`: `cn` now re-exports from the `cn` package (what the registry delivers; the package was already a dependency).
- `package.json`/lockfile: added `@base-ui/react`, `@fontsource-variable/inter`, `shadcn`; removed `radix-ui`.
- All 7 ui wrappers re-added from base-vega (see their own files).
- `src/routeTree.gen.ts`: regenerated by the build (Register typing for createStart).

## Left alone

- `clsx` / `tailwind-merge` are still installed but nothing in src imports them any more. Not removed.
- No cmdk/vaul/sonner/input-otp/calendar/chart wrappers exist.

## Behavior changes

- The visual style changed (new-york → vega, zinc → neutral, Inter font). This was intended.

## Verify by hand

- `pnpm dev`, open /, and check that the background and text follow the theme. Toggle `.dark` on <html> and check that the dark tokens apply.

Final check: `pnpm build` passes. `tsc --noEmit` shows 1 error, `drizzle.config.ts` (dbCredentials url may be undefined), which was there before this work.
